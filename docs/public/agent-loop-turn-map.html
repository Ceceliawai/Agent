DSH Agent orchestration

一个 Turn 的操作、事件与监听器

执行主线由 Agent Loop 驱动；Cordis 负责分派控制事件；已挂载插件提供策略；Session Log 保存模型可见事实并向客户端投影。

Agent Loop

拥有 Turn/Step 状态机，决定何时调用模型、工具以及何时收敛。

Cordis

执行 waterfall、serial 和 emit，并按 Agent Scope 隔离监听器。

DSH Plugins

在事件点注入压缩、指令、路由、重试、权限与 Hook 策略。

Session Log

记录持久事实，支持恢复、回放和 WebSocket 前端投影。
